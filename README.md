## 这是什么？

**MONO CODE** 品牌下的第一个开源产品。核心理念来自一个简单的事实：

> **数量不稀释纯度，不落地才稀释纯度。**

「源进化」不是待办清单，而是一个**具象化的自我打造系统**：

```
选身份 → 拆解为最小行动 → 今日落地 → 获得修为 → 复盘沉淀 → 原思维积累
```

### 核心功能

| 模块 | 说明 |
|------|------|
| **💡 灵感** | 写下真实目标，一键拆解为「准备→执行→沉淀」三段可验证的最小行动 |
| **✅ To-Do** | 逐项打卡落地，每完成一步获得修为，勾选瞬间有弹性反馈 |
| **⬆️ 境界** | 修为累积升级，从「初醒」到「宗师」的五阶转职路线，经验条动态充能 |
| **🧠 记忆** | 复盘归档+即时捕捉+语音输入，沉淀为你的「原思维」积木 |

### 首次进入：身份选择

打开页面先选身份（学生/制作者/创作者/探索者），系统会按你的处境给出贴合日常的灵感示例：

| 身份 | 示例（颗粒度 = 今天就能做完的最小动作） |
|------|------|
| 🎒 学生 | 背完九九乘法表一行 / 预习明天两页课本 / 半页练习册自检 |
| 🛠️ 制作者 | 修好家里小物件 / 写20行脚本 / 清理手机存储 |
| 🎬 创作者 | 写300字日记 / 拍3张照片 / 录1分钟语音随笔 |
| 🧭 探索者 | 学一道新菜 / 走3000步 / 读30页书 |

零 AI、纯本地，打开即用。

## 快速开始

1. 下载 `index.html`
2. 用浏览器打开
3. 选身份 → 写目标 → 拆解 → 打卡 → 沉淀

**无需注册、无需联网、数据全部存在本地 localStorage。**

## 技术栈

| 技术 | 用途 |
|------|------|
| 单文件 HTML | 零依赖、零构建，一个文件就是整个产品 |
| GSAP 3.12 | 入场动效 / 导航图标动画 / 经验条充能 / 粒子特效 |
| localStorage | 数据持久化，key = `sourcevolve_v1` |
| Web Speech API | Chrome/Edge 原生语音输入（记忆页即时复盘） |

### 浏览器支持

| 浏览器 | 支持情况 |
|--------|---------|
| Chrome / Edge | ✅ 完整支持 + 语音输入 |
| Safari / Firefox | ✅ 完整支持（语音输入暂不可用） |
| 移动端 | ✅ 响应式适配，时长自动优化 |

## 背后的故事

MONO CODE 始于一个 18 岁开发者的日常实践：

> 「我每天拆很多东西：清灰、装系统、配环境、部署项目……我发现学习能力像多模态模型一样，是指数级增长的。但前提是——**每个目标都要被拆到最小、被真正落地、被复盘沉淀**。」

这个工具就是那个实践过程的产物。它不是「帮你管理时间」的软件，而是一个**让成长变得可见的游戏化系统**。

如果你也相信「做到落地」比「想得完美」更重要，欢迎同行。
